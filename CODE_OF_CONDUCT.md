# Code of conduct

Participation in this project must remain respectful, constructive, and
focused on the software.

Harassment, threats, discrimination, publishing another person's private
information, and deliberately disruptive behavior are not acceptable.
Technical disagreement is welcome when expressed in good faith and supported
with evidence.

The repository owner may edit, hide, or remove contributions and may restrict
participation when necessary to protect the project or its participants.
Report conduct concerns privately through the contact method on the repository
owner's GitHub profile.
